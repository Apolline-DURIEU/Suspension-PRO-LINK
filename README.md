# Suspension Pro Link 🏍️🛞
## Projet sur Ansys Motion - Mécanique des Systèmes Multicorps

Mini projet d'étude d'une suspension PRO LINK sur Ansys Motion.  
Ce projet a eu lieu dans le cadre de cours sur la mécanique des systèmes à plusieurs corps. 

Les Suspensions PRO LINK qui ont été étudiées sont des suspensions couramment utilisées pour les motos 🛵, et sont composées de multiples pièces qui doivent être optimisées afin de trouver un bon équilibre entre le confort du conducteur et la bonne tenue de la route.
